Сформируй аналитический торговый план (не приказ).

Верни JSON:
{
  "summary": "...",
  "scenario": {
    "type": "LONG|SHORT",
    "activation": ["условия активации"],
    "invalidation": ["условия недействительности"],
    "targets": ["TP1...", "TP2..."]
  },
  "strengths": ["..."],
  "risks": ["..."],
  "confidence": 0-100,
  "explanation": "текст плана на русском"
}

Не пиши "покупай/продавай". Пиши "сценарий при выполнении условий".
